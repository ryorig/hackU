# パズルソルバー

2次元グリッドパズルを解くためのビームサーチベースのソルバー

## アルゴリズム

### ビームサーチ
- 幅優先探索の変種で、各深度で最良の60個の状態のみを保持
- f値（実コスト + ヒューリスティック）が小さい順に優先探索

### ヒューリスティック関数
- 各値の2つの出現位置のマンハッタン距離を計算
- 距離が1（隣接）を超える場合、その超過分をペナルティとして累積
- h = 0 で解発見

### 最適化技術
1. **Zobristハッシュ**: 状態の重複検出を高速化（O(1)比較）
2. **差分更新**: 変更部分のみ処理してヒューリスティック計算を高速化
3. **並列処理**: 8スレッドで状態展開を並列実行

### 操作
グリッド上の正方形領域（2×2〜6×6）を時計回りに90度回転
